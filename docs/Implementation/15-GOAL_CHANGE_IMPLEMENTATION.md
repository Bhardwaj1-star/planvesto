# Goal Change Implementation

Goal Change → Recalculate Goal → Feasibility → Impact Check → Targeted/Whole-Plan Revalidation → Recommendation → Adoption. Keep the changed goal proposed until adopted; identify affected funding, Strategies and actions.

Use Whole-Plan Impact when the change creates material resource competition or plan conflict.

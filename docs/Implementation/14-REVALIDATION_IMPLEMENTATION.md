# Revalidation Implementation

Flow: Material Trigger → Impact Analysis → Affected Areas → Targeted Revalidation → Still Valid? YES: continue/update execution. NO: affected planning/Strategy Decision → recommendation → investor adoption → updated Accepted Plan.

Triggers include Financial State, Goal, new Goal, Strategy, execution and material assumption changes. Determine materiality first and avoid unnecessary full-plan rebuilds.

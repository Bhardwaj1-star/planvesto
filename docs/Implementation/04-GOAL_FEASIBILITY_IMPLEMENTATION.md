# Goal Feasibility Implementation

Calculate future target and funding gap, derive required contribution, and compare it with available investable surplus. Return Feasible / Constrained / Infeasible / Unknown with evidence and assumptions.

Do not force Debt Reduction or Credit Utilisation because a gap exists. For material multi-goal conflicts, hand off to Whole-Plan Impact.

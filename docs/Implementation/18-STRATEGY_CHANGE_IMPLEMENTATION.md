# Strategy Change Implementation

Strategy Change → Evaluate Alternative → Compare Impact/Trade-offs → Implementation → Stress/Resilience → Recommendation → Adoption.

Preserve the current accepted Strategy until the new one is accepted. Re-run affected applicability/viability and downstream implementation. Compare goal outcome, cash flow, risk, constraints and execution implications.

# Goal Planning Implementation

Flow: Goal Input → Normalisation → Timeline → Future Target → Asset Mapping/Projection → Funding Gap → Required Contribution → Financial Capacity → Defined Goal.

Create a versioned Defined Goal containing canonical type, target date, priority/flexibility, inflation/future target, mapped assets, funding gap and required contribution. Goal Funding is a Goal Planner/feasibility function, not a Strategy Builder Strategy.

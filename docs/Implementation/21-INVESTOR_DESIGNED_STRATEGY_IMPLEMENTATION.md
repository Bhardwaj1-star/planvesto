# Investor-Designed Strategy Implementation

Investor Proposal → Capture Logic → Constraint/Feasibility Review → Impact/Stress Review → Investor Review → Accept / Modify / Reject.

Capture investor objective, choices and rationale. Do not mislabel it as a standard Strategy. Test against evidence and constraints; surface risks, gaps, trade-offs and dependencies. Accepted proposals are explicitly tagged and versioned.

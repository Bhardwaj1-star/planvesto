# Financial State Implementation

Maintain a validated, versioned current financial position: income, expenses, assets, liabilities/debt, capacity, derived indicators and data-quality flags. Keep entered values separate from derived values and preserve state history.

Material changes identify affected goals/Strategies and trigger targeted revalidation. Financial State is evidence, not Strategy.

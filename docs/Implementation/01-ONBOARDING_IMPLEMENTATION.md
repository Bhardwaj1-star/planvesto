# Onboarding Implementation

Validate and normalise investor inputs, create the initial Financial State snapshot, record missing/inconsistent data, and initialise goal intent. Never invent facts or select a Strategy during onboarding.

Handoff: Onboarding → Financial State → Goal Planning.

References: `docs/User Journeys/02-ONBOARDING_JOURNEY.md`, `docs/architecture/goal-planner.md`.

Acceptance: reproducible initial state with visible validation issues.

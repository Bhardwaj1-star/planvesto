# Implementation System Map

Implementation is the engineering layer between approved product decisions and code. Source authority: business decisions → Decision Tree → Architecture → User Journeys → Real-Life Cases → current code evidence.

Flow: Business Requirement → Canonical Rule → Existing Architecture → Existing Code → Required Change → Data/Interfaces → Validation → Acceptance Criteria.

Rules: do not create a second business model; preserve Strategy → Variant → Technique → Method/Policy → Solution → Action; Goal Funding belongs to Goal Planner/feasibility; proposed and accepted plans stay separate; current code is not authority when it conflicts with approved decisions.

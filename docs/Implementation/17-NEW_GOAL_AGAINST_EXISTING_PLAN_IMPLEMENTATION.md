# New Goal Against Existing Plan Implementation

New Goal → Goal Planning/Feasibility → Existing Plan Impact → Whole-Plan/Multi-Goal Impact → Investor Decision → Updated Plan if accepted.

Do not silently consume resources committed to accepted goals. Show competition, priority trade-offs, cash-flow effects and alternatives. Rejected new goals do not alter the Accepted Plan.

# Multi-Goal Whole-Plan Implementation

Use for resource competition and material cross-goal effects. Flow: multiple goals/material plan change → goal-level feasibility → Whole-Plan Impact → conflicts/trade-offs → investor review → adoption.

Preserve each goal's evidence, model shared resources, identify conflicts and recalculate affected goals. Whole-Plan Impact is conditional, not part of every individual-goal Strategy Decision.

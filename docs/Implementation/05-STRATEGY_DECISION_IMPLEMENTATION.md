# Strategy Decision Implementation

Canonical flow: Goal Context + Financial State + Feasibility/Funding Evidence + Constraints → Constraint/Safety Evaluation → Strategy Applicability → Candidate Viability → Strategy Selection → Variant → Technique → Method/Policy → Architecture/Solution → Stress/Resilience → Decision/Recommendation.

Strategies: Progressive De-risking, Capital Preservation, Debt Reduction, Credit Utilisation, or No acceptable Strategy. Do not jump from goal type/horizon directly to Strategy. Credit must fail when capacity, EMI sustainability, financing economics or repayment path is unacceptable. Whole-Plan Impact is conditional, not mandatory for every individual goal.

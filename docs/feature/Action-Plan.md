# Action Plan

## Purpose
Accepted Plan ko investor ke liye concrete actions mein badalna aur unki execution progress track karna.

## Scope
- Accepted path se required actions identify karna.
- Har action ko relevant goal ya plan se link karna.
- Defined details—purpose, amount, timing, priority, sequence, dependencies, source aur destination—dikhana.
- Investor ke action decisions aur execution progress track karna.
- Execution ke actual result ko expected impact se compare karna.
- Accepted path badalne par affected future actions update karna aur completed actions ka record preserve karna.

## Ownership
- **Goal Planner / Goal Feasibility:** goal funding, shortfall aur required financial changes.
- **Strategy Builder / Implementation:** selected strategy ke implementation steps.
- **Investor Decision / Accepted Plan:** kaunsa proposed path adopt hua.
- **Action Plan:** adopted path ke actions aur execution progress.
- **Impact Analysis / Revalidation:** change ke baad affected decisions ko dobara check karna, jab zaroori ho.

## Scope Boundary
Action Plan strategy select nahi karta aur Goal Feasibility ko independently dobara solve nahi karta. Recommendation ya What-If scenario apne aap active Action Plan nahi banta. Revised actions tab update hote hain jab investor revised path adopt karta hai.

## Action Sources
Accepted financial path ke mutabik actions in se aa sakte hain:
- Goal funding / feasibility changes.
- Debt repayment, restructuring ya EMI/cash-flow changes.
- Goals ke beech accepted resource allocation.
- Strategy aur implementation steps.
- Investor-adopted execution changes.

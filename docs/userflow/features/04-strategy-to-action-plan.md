# Strategy → Action Plan

```text
User
└── Strategy select karta hai
    └── Selected Strategy Version
        └── User approval
            └── Approved Strategy
                └── Action Plan
                    ├── Kya karna hai?
                    ├── Kis strategy ke liye?
                    └── Expected impact kya hai?
                        └── User action complete karta hai
                            └── Actual result
                                └── Financial State update
                                    └── Next planning decision
```

# Goal Planner

```text
User
└── Goal select / enter karta hai
    └── Goal ki details
        ├── Goal type
        ├── Target
        ├── Time
        └── Priority
            └── System goal ko standard form me rakhta hai
                └── Goal funding check
                    ├── Shortfall
                    ├── On Track
                    └── Overfunded
                        └── Feasibility check
                            ├── Financial State available?
                            │   ├── No → Feasibility unknown
                            │   └── Yes
                            │       └── Available surplus dekho
                            │           ├── Goal fund ho sakta hai
                            │           └── Funding limitation hai
                            └── Result
                                └── Strategy ke liye goal ready
```

# Planvesto User Flow

```text
USER
└── Financial Picture
    └── Financial State
        └── Goals + Constraints
            └── Goal Funding
                └── Feasibility
                    └── Strategy Options
                        └── User Selection
                            └── Strategy Version
                                └── Approval
                                    └── Actions
                                        └── Actual Financial Change
                                            └── Financial State
                                                └── Next Planning Cycle
```

## Main Flows

```text
User
└── 1. Financial Picture
    └── Financial State
        └── Goals + Constraints

User
└── 2. Goal Funding
    └── Goal
        └── Funding
            └── Feasibility

User
└── 3. Strategy Choice
    └── Goal + Financial Situation
        └── Strategy Options
            └── User Selection
                └── Strategy Version

User
└── 4. Approval → Action
    └── Strategy Version
        └── Approval
            └── Actions
                └── Actual Financial Change
                    └── Financial State

User
└── 5. Goal Change
    └── New Goal Version
        └── New Strategy Version
            └── New Approval
                └── New Actions
```

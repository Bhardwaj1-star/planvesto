# Investor-Designed Strategy Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
No / Unsuitable Standard Path → Investor Proposes Own Approach
→ System Captures Proposed Logic → Constraint / Feasibility Review
→ Impact / Stress Review → Investor Reviews Result
→ Accept as Investor-Designed Strategy / Modify / Reject
```

## Investor Does
- Defines the intended approach.
- Explains the objective and key choices.
- Decides whether the reviewed approach is acceptable.

## System Does
- Tests the proposed approach against evidence and constraints.
- Identifies risks, gaps and trade-offs.
- Does not label an investor-designed approach as a standard Strategy.

## Core Rule

Investor-designed Strategy is an **explicit alternative mode**, not a hidden fallback that bypasses validation.

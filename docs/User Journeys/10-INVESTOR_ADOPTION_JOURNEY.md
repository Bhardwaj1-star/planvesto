# Investor Adoption Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Recommendation → Investor Reviews → Accept / Reject / Modify
```

### Accept
```
Accept → Accepted Plan
```

### Reject
```
Reject → Existing Accepted Plan remains
```

### Modify
```
Modify → Relevant planning / strategy stage → Recalculate
→ New Recommendation
```

## Core Rule

The system must never treat a recommendation as accepted without an investor decision.

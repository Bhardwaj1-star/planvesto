# Goal Change Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Investor changes Goal Intent / Assumption → Recalculate Goal
→ Goal Feasibility → Does change affect existing plan?
   ├─ No → Continue affected goal flow
   └─ Yes → Whole-Plan / Targeted Impact
           → Revalidate affected Strategy
           → Recommendation → Investor Adoption
```

## Investor Controls
The investor decides the new goal intent, target, scope or relevant assumption.

## System Controls
The system identifies affected downstream outputs and recalculates them.

## Core Rule

A changed goal is a **proposed change** until the investor adopts the resulting plan.

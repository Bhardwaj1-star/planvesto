# Strategy Change Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Investor requests Strategy Change → Review Current Accepted Strategy
→ Evaluate Alternative → Compare Impact / Trade-offs
→ Implementation Design → Stress / Resilience
→ Recommendation → Investor Adoption
```

## Investor Sees
- Current Strategy
- Proposed Strategy
- Reason for change
- Impact on goal / cash flow / risk
- Implementation differences

## Core Rule

A Strategy change is not complete when the alternative is calculated. It becomes effective only after investor adoption.

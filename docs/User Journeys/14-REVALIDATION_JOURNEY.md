# Revalidation Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Material Change / Trigger → Impact Analysis → Identify Affected Areas
→ Targeted Revalidation → Still Valid?
   ├─ Yes → Continue
   └─ No → Affected Planning / Strategy Decision
           → New Recommendation → Investor Adoption
```

## Possible Triggers
- Financial State change
- Goal change
- New goal
- Strategy change
- Execution change
- Material assumption change

## Core Rule

Revalidation should be **targeted**. Do not rebuild unrelated parts of the plan when the change does not affect them.

# Financial State Change Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Financial State Changes → Materiality Check → Identify Affected Goals / Strategies
→ Targeted Revalidation → Still Valid?
   ├─ Yes → Continue Existing Plan
   └─ No → Replanning / Strategy Decision
           → Recommendation → Investor Adoption
```

## Examples
- Income changes
- Expense changes
- New debt
- Debt repayment
- Asset changes
- Available surplus changes

## Core Rule

A Financial State change does not automatically invalidate the whole plan. Determine the affected scope first.

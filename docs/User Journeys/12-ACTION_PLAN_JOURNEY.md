## 1. Main Journey

```
Accepted Plan
     ↓
Required Actions
     ↓
Action List
     ↓
Investor Review
     ↓
Confirm / Change / Reject
     ↓
Execution
     ↓
Progress Update
     ↓
Impact Check
```

       ┌────┴────┐

       ↓         ↓

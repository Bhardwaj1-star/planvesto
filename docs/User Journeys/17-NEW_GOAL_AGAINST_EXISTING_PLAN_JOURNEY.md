# New Goal Against Existing Plan Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Investor proposes New Goal → Goal Planning / Feasibility
→ Compare with Existing Accepted Plan → Whole-Plan / Multi-Goal Impact
→ Investor reviews trade-offs → Accept / Reject / Modify
```

## If Accepted

```
New Goal → Affected Planning / Strategy → Updated Recommendation
→ Investor Adoption → Updated Accepted Plan
```

## If Rejected

```
Reject → Existing Accepted Plan remains
```

## Core Rule

A new goal must not silently consume resources already committed to existing accepted goals.

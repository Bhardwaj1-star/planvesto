# Stress / Resilience Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Proposed Plan → Stress / Resilience Tests → Pressure Points
→ Investor sees resilience result → Accept / Modify / Reconsider
```

## Investor Sees
- Key risks or pressure points
- Effect on goal funding
- Effect on affordability / cash flow
- Whether the proposed approach remains acceptable

## System Does
- Tests relevant adverse conditions.
- Measures impact.
- Flags material weakness.
- Does not present stress results as guaranteed forecasts.

## Core Rule

Stress testing informs the decision. It does not silently change the investor's plan.

# Strategy Decision Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Defined Goal + Financial State + Feasibility Evidence + Constraints
→ Constraint / Safety Check → Strategy Applicability → Candidate Viability
→ Strategy Selection → Variant → Technique → Method / Policy
→ Architecture / Solution → Stress / Resilience → Decision / Recommendation
```

## Investor Experience

1. Reviews the goal and financial position.
2. Sees viable approaches.
3. Understands why an approach fits.
4. Reviews trade-offs and constraints.
5. Receives a recommendation.
6. Decides whether to adopt it.

## Strategy Choices

- Progressive De-risking
- Capital Preservation
- Debt Reduction
- Credit Utilisation
- No acceptable Strategy, where applicable

## Core Rule

The system should not jump directly from goal type or horizon to a Strategy. Strategy selection follows evidence and constraints.

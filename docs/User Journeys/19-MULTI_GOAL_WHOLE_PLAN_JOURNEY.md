# Multi-Goal / Whole-Plan Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Multiple Goals / Material Plan Change → Goal-Level Feasibility
→ Whole-Plan Impact → Identify Resource Conflicts
→ Compare Goal Trade-offs → Investor Reviews
→ Accept / Reject / Modify → Updated Plan
```

## Investor Sees
- Effect on each affected goal
- Resource competition
- Priority trade-offs
- Funding / cash-flow implications
- Resulting plan alternatives

## Core Rule

Whole-Plan analysis is **conditional**. It is used when a decision materially affects multiple goals or shared resources.

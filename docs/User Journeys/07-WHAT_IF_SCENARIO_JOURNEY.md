# What-If Scenario Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Current / Proposed Plan → Investor asks "What if?"
→ Change assumption → System recalculates → Impact Comparison
→ Investor reviews → Keep current / Adopt change
```

## Typical What-Ifs
- Change goal date.
- Change contribution.
- Change asset mapping.
- Change Strategy or implementation choice.
- Change an execution action.

## Investor Sees
- Current position
- Scenario position
- Material differences
- Key trade-offs

## Core Rule

A scenario is **not automatically the accepted plan**. Adoption requires an investor decision.

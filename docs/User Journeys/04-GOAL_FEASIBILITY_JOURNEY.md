# Goal Feasibility Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Defined Goal → Funding Requirement → Available Financial Capacity
→ Feasibility Assessment → Investor Reviews Result
```

| Result | Investor experience |
|---|---|
| Feasible | Continue to Strategy Decision |
| Constrained | Review pressure and possible adjustments |
| Infeasible | Review shortfall and possible adjustments |
| Unknown | Provide missing evidence |

## Investor Decision

```
Result → Accept current assumptions?
       ├─ Yes → Continue
       └─ No → Adjust → Recalculate
```

## Core Rule

Infeasibility does not automatically mean Credit Utilisation or Debt Reduction. The goal remains the investor's decision.

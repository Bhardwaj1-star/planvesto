# Decision & Recommendation Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Planning Evidence → Strategy / Implementation → Stress / Resilience
→ Decision Synthesis → Recommendation → Investor Review
```

## Investor Sees
- Recommended path
- Why it fits
- Important trade-offs
- Constraints
- Key assumptions
- Alternatives where relevant

## Investor Decision

```
Recommendation → Accept / Reject / Modify
```

## Core Rule

Recommendation is a decision-support output. The investor remains the decision-maker.

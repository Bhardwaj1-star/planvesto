# Accepted Plan Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Investor Accepts Recommendation → Accepted Plan Created / Updated
→ Plan Version Recorded → Investor Reviews Accepted State
→ Action Plan → Execution
```

## Investor Sees
- What has been accepted
- Goals covered
- Selected Strategies
- Implementation structure
- Important assumptions and dependencies

## System Does
- Preserves the accepted version.
- Separates proposed scenarios from accepted state.
- Creates a stable basis for Action Plan and Execution.

## Core Rule

A proposed or rejected plan must not overwrite the existing Accepted Plan.

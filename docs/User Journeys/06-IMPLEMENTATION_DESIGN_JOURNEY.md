# Implementation Design Journey

**Document Type:** User Journey  
**Status:** CANONICAL DESIGN

## Journey

```
Selected Strategy → Variant → Techniques → Methods / Policies
→ Architecture / Solution → Implementation Requirements → Investor Review
```

## Investor Does
- Reviews how the selected Strategy will be implemented.
- Reviews required changes, trade-offs and dependencies.
- Confirms whether the implementation is practical.

## System Does
- Converts the selected Strategy into an implementable structure.
- Composes relevant techniques and solutions.
- Identifies dependencies and constraints.
- Does not silently execute changes.

## Handoff

```
Implementation Design → Stress / Resilience → Decision / Recommendation
```
